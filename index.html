Proyecto destacadoEn desarrollo

NVR System

Sistema de grabación de cámaras IP desarrollado con Python. El proyecto reúne descubrimiento de dispositivos con ONVIF, conectividad RTSP y grabación mediante FFmpeg, con PostgreSQL, Docker y pruebas unitarias.

Su diseño separa responsabilidades entre componentes como RecordingService, RecordingManager, VideoRecording y RecordingStorage para gestionar grabaciones, procesos de vídeo y almacenamiento.

  • Python
  • ONVIF
  • RTSP
  • FFmpeg
  • PostgreSQL
  • Docker
